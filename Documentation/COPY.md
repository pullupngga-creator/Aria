# COPY.md — Aria UI Text

## Brand Voice
- **Tone**: Direct, calm, trustworthy, minimal. No hype, no exclamation points.
- **Style**: Short sentences. Active voice. Technical precision where needed. Respect user privacy.
- **Avoid**: "Amazing!", "Super fast!", "Just click here!", emojis in primary UI.

---
